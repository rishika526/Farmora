# 🌱 Farmora

> **From soil to solution — organic made practical.**

Farmora is an AI-powered smart agriculture platform that connects learners, creators, and organic farming enthusiasts in one ecosystem. It provides personalized learning, intelligent recommendations, organic farming kits, and quantum-inspired optimization to make sustainable farming more accessible.

🌐 **Live Demo:** https://farmora-3m2h.onrender.com/

# ⚛️ Quantum Computing in Farmora

Farmora goes beyond traditional recommendation systems by integrating **Quantum-inspired Optimization**.

Instead of recommending random tutorials, the platform intelligently selects the best learning content using optimization algorithms.

### Implemented Concepts

- QUBO (Quadratic Unconstrained Binary Optimization)
- Simulated Annealing
- QAOA Simulation
- Fair Creator Optimization
- Smart Farm Task Planning

These techniques help optimize:

- Tutorial recommendations
- Organic kit recommendations
- Creator visibility
- Farm activity scheduling

# 🖥️ Installation

Clone the repository

```bash
git clone https://github.com/rishika526/farmora.git
```

Move into the project

```bash
cd farmora
```

Install dependencies

```bash
npm install
```

Create environment variables

```env
DATABASE_URL=your_database_url
```

Run the project

```bash
npm run dev
```
